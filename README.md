# Generatore di Password Pro

Sicurezza. Semplicità. Stile. Questa web app ti permette di generare password complesse e personalizzabili in pochi click, con un'interfaccia moderna ed elegante.

## Caratteristiche Principali

- Generazione di password complesse e personalizzabili.
- Interfaccia utente moderna ed elegante.
- Facile da usare.

## Tecnologie Utilizzate

- React
- Vite
- TypeScript

## Esecuzione Locale

Per eseguire l'applicazione in locale, segui questi passaggi:

**Prerequisiti:**

- Node.js (versione consigliata: 14 o superiore)

**Installazione:**

1. Clona il repository (se applicabile) o scarica i file del progetto.
2. Naviga nella directory principale del progetto.
3. Installa le dipendenze:
   ```bash
   npm install
   ```

**Configurazione:**



**Esecuzione:**

1. Avvia l'applicazione in modalità sviluppo:
   ```bash
   npm run dev
   ```
2. Apri il tuo browser e vai all'indirizzo mostrato nella console (solitamente `http://localhost:5173/`).

## Build per la Produzione

Per creare una build ottimizzata per la produzione:

```bash
npm run build
```

Questo creerà i file di build nella directory `dist`.

## Preview della Build

Per visualizzare in anteprima la build di produzione localmente:

```bash
npm run preview
```

Questo avvierà un server locale per servire i file dalla directory `dist`.
